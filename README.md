# ESTE SON NOTAS DE PYTHON:
Convenciones para nombrar identificadores en Python
1. El nombre de una variable debe comenzar únicamente con una letra o un guion bajo (_).
2. El nombre de una variable puede contener números, pero estos solo pueden aparecer después de la primera letra o del guion bajo. También puede contener letras del alfabeto y guiones bajos. No se permiten espacios en blanco.
3. En Python no existe una restricción específica sobre la longitud del nombre de una variable.
4. Los identificadores distinguen entre mayúsculas y minúsculas (Case Sensitive). Por ejemplo, num, Num y NUM son considerados diferentes.
5. Los identificadores no pueden tener el mismo nombre que las palabras reservadas del lenguaje Python.


Categorías de los tipos de datos en Python
1. Tipo de texto (Text Type): str
Se utiliza para almacenar cadenas de texto.
2. Tipos numéricos (Numeric Types): int, float, complex
int: números enteros.
float: números decimales.
complex: números complejos.
3. Tipos de secuencia (Sequence Types): list, tuple, range, set
list: listas.
tuple: tuplas.
range: rangos de números.
set: conjuntos.
4. Tipo de mapeo (Mapping Type): dict
Se utiliza para almacenar datos mediante pares de clave y valor.
5. Tipo booleano (Boolean Type): bool
Representa dos valores: True (verdadero) y False (falso).
